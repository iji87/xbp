gitとは

Gitはファイルのバージョンを管理するためのソフトでSCM（Source Code Management）の一つです。
また、このソフトには二つの重要な役割があります。
  • ファイルの情報管理
  • ファイルの変更履歴管理

リポジトリとは

リポジトリとは、Gitで管理されているファイルの集まりのことです。
また、リポジトリには二つの種類があります。
  • ローカルリポジトリ
  • リモートリポジトリ
リモートリポジトリはWeb上に置かれており、一つのGitシステムに一つ設置して、各ユーザー共通で使用します。
ローカルリポジトリは各ユーザーがPC上に持っています。

4つのアクション

add

addは、コミットを行う前の準備のようなもので、ファイルを編集したことをインデックスに登録するアクションです

commit

commitは、インデックスに登録されたファイルをローカルリポジトリに保存するアクションです。

push

pushは、ローカルリポジトリの変更をリモートリポジトリに送信するアクションです。

pull

pullは、リモートリポジトリの変更をローカルリポジトリに反映させるアクションです。

htmlとは

HTMLはHyperText Markup Languageの略で、ウェブページを構成するためのマークアップ言語です。
[Markup]とは、文章の構造や意味を示すために、文字や記号を使って情報を付加することを指します。
例えば、見出しや段落・表・リンクなど、文章が構成されている要素がどのような役割を持っているかを指示しています。

htmlの基本構造

  1. タグ

    2. 「タグ」とは「文字（テキスト）に意味を与えてあげる印のようなもの」です。
    文字をタグで囲うと、ただの文字がh1（見出し）やp（段落）といった意味を持つようになります。
  2. 要素

    3. 要素とは、タグの種類を表す文字列のことです。
    HTMLのコードでは、各要素のタグとそれに「/」を付けた終了タグで対象の文字列を囲む書き方が一般的です。
  3. 属性

    4. 属性とは、要素に対して様々な機能を追加するためのものです。
    属性を指定することで、表示する内容やクリックされた時の挙動などを調整できます。
